# Introducción
En esta sección hay distintas pruebas realizadas como distintas longitudes de textos ingresadas y comparadas con el modelo de Google.

En ambos textos se realizó un análisis y conclusión del experimento realizado.

# Análisis General
En el primer experimento con un texto corto comparando ambos modelos se pudo detectar que el motor de **Google** realiza una construcción más descriptiva, mientras que el motor de **Microsoft** conserva ligeramente más una estructura original, demostrando que cada motor puede recuperar el significado aunque no recupere las mismas palabras al volver a su idioma original.

Dentro del experimento de sesgo y ambigüedad, ambos motores tuvieron problemas evidentes para determinar correctamente el género cuándo la información necesaria aparecía posteriormente en el texto. También se observo dificultad con el "_they_", aunque en inglés puede utilizarse para una persona cuyo género es desconocido, ambos motores lo transformaron en una forma plural, generando una construcción diferente a la original y puede generar problemas dependiendo del contexto.

# Conclusión
Los experimentos muestran que ambos motores (**Google Translator** y **MyMemory**) presentan buena capacidad para conservar el significado general del texto (en esta ocasión con estructuras corta o sencilla), pero esto no quiere decir que mantengan exactamente la estructura original, esto puede cambiar dependiendo de ciertas variantes, como la ortografia, la longitud del texto, caracteristicas culturales no reconocidos o interpretados en otros idiomas.

Por otro lado, el test de sesgo y ambigüedad demostros grandes dificultades al interpretar el contexto cuándo trata sobre determinar el género que no está expresado directamente en inglés o resolver información ambigua.

De este modo, aunque ambos motores pueden producir traducciones adecuadas en situaciones sencillas, la supervisión humana es importante en textos donde una decisión lingüistica puede modificar el significado o la interpretación del texto original.
